🧠 NeuroNEET

Train the Brain. Conquer NEET.

NeuroNEET is an AI-powered NEET preparation command center designed to help students study smarter, practise consistently, revise effectively, and track their academic progress.

Built with a futuristic OLED-black interface and neon-inspired visuals, NeuroNEET brings essential study tools, subject-wise learning modules, mock examinations, performance tracking, and AI-powered guidance into one unified platform.

«Created & Developed by RIDDHI DAS & ANSHU BHIUYA»

---

🚀 Core Features

📊 1. Dashboard — Your Study Command Center

The dashboard provides a central place to manage daily preparation.

- Focus Timer: Track focused study sessions using the built-in timer.
- Today's Targets: Create and manage daily study goals.
- Consistency Tracker: Monitor study consistency and maintain your streak.
- Progress Overview: Keep important study information accessible from one screen.
- Master Reset: Reset application data when necessary.

🧬 2. Biology Master

A dedicated learning space for Class 11 and Class 12 Biology, built around active recall and NCERT revision.

- Active Recall: Create flashcards with questions and answers to test your memory.
- Diagram Vault: Learn through labelled biological diagrams, including the human heart and brain.
- NCERT Tracker: Track chapter-wise syllabus completion for both classes.

The goal is to make Biology revision more organised and help students identify topics that need further practice.

⚡ 3. Physics Command

A collection of tools designed to support conceptual understanding, formula revision, and numerical problem-solving.

- Formula Hub: Store and revise important Physics formulas, including mathematical expressions.
- Mistake Notebook: Record calculation errors and conceptual mistakes for later review.
- Shortcut Tricks: Save useful problem-solving methods and revision tips.
- Syllabus Tracker: Monitor chapter-wise progress across Class 11 and Class 12.

🧪 4. Chemistry Hub

A dedicated workspace for organising reactions, revision material, and syllabus progress.

- Organic Flow-Maps: Create and organise reaction pathways and connected concepts.
- Custom Reaction Quiz: Add questions and answers to practise chemical reactions.
- Syllabus Tracker: Monitor Chemistry preparation across both classes.

📝 5. Mock Engine

The Mock Engine provides an examination-style environment for practising under timed conditions.

- Exam Timer: Supports the standard NEET examination duration of 3 hours and 20 minutes.
- Digital OMR Sheet: Select answers using an on-screen answer sheet.
- Automatic Grading: Evaluate submitted answers against the configured answer key.
- Results Panel: Review the results after completing a test.
- Exam Controls: Start, end, view results, and reset tests.

AI-generated questions can also be integrated into this system as the project develops.

📚 6. PYQ Vault

The Previous Year Question Vault helps organise questions and solutions in one searchable workspace.

- Save questions with their answers or solutions.
- Categorise questions by year and subject.
- Filter saved questions for targeted revision.
- Build a personal question bank for repeated practice.

The current interface includes year filters for 2021–2025, with scope for expanding the collection.

🤖 7. Neura AI — Your AI Study Assistant

Neura AI is the intelligent assistance system planned for NeuroNEET. It has two main interfaces:

- Floating AI Assistant: A quick-access interface for asking doubts and requesting explanations.
- Neura AI Hub: A dedicated workspace for more advanced study tasks.

Planned AI capabilities include:

- Generating NEET-style MCQs and assertion–reason questions.
- Creating topic-specific practice tests.
- Helping build revision plans and study schedules.
- Analysing quiz performance and identifying weak chapters.
- Recommending topics for further practice.
- Connecting generated questions with the Mock Engine and OMR system.

AI features require an internet connection and access to a configured AI API. Their actual capabilities depend on the implemented backend and selected AI model.

📈 8. Progress & Consistency

NeuroNEET aims to help students understand not only what they have studied, but also where their preparation needs attention.

The planned progress system brings together study consistency, completed goals, syllabus progress, mock-test performance, and revision priorities.

Future versions may include a Neura Insights dashboard that summarises weak topics and suggests the next useful study task.

NeuroNEET uses a futuristic, mobile-first interface featuring:

- Font Awesome icons.

---

🛠️ Technology Stack

The current web interface is built around:

- HTML5 — Application structure.
- CSS3 — Styling, responsive layouts, and visual effects.
- JavaScript — Interface interactions and application functionality.
- MathJax — Rendering mathematical expressions.
- Font Awesome — Icons.
- Google Fonts — Interface typography.

AI Backend & Security

Neura AI is intended to communicate with an AI model through a backend service, such as a Cloudflare Worker.

The frontend should send requests to the backend rather than contain a private API key. Secrets should be stored securely as server-side environment secrets, alongside appropriate request validation and usage limits.

Android Support

The web application can potentially be packaged as an Android app using a framework such as Capacitor. Android packaging, offline caching, and native integrations depend on the additional configuration and implementation required.

---

🌐 Online & Offline Approach

NeuroNEET is planned around a hybrid architecture.

Potentially available offline: Core study tools, saved revision material, timers, trackers, and locally stored questions—provided persistence and offline caching are implemented correctly.

Online-dependent: Neura AI features that communicate with an external AI service.

Offline availability depends on the final storage system, service worker configuration, and whether required resources are cached locally.
